# github-develop

My GitHub operating system. This repo holds the plan, the standards, and the
templates I use so that every project I build ends up on GitHub properly
instead of dying in a local folder.

Owner: divitkej (BITS Pilani, Dubai Campus)
Started: September 2026, second year
Target: a profile that reads as "this person ships" by graduation (mid-2029)

## What is in here

| Path | What it is |
| --- | --- |
| `docs/ROADMAP.md` | Semester by semester plan from now to graduation |
| `docs/WORKFLOW.md` | The git and GitHub habits, with exact commands |
| `docs/REPO_STANDARDS.md` | The bar every repo I own has to clear |
| `docs/PROFILE_README.md` | Draft of the profile README for `divitkej/divitkej` |
| `docs/WEEKLY_LOG.md` | Running log of what I shipped each week |
| `templates/` | Starter README, LICENSE, .gitignore, PR and issue templates |
| `scripts/new-project.sh` | Scaffolds a new project that already meets the standards |

## The one rule

Green squares are a side effect of building things, not the goal. No commit
bots, no cron jobs that edit a text file at midnight, no "daily streak" repos.
Recruiters and professors open the repos, not the graph. A fake graph with
empty repos behind it is worse than no graph.
