# Weekly log

One entry per week, added on Sunday. Takes three minutes. By the time you are
sitting in an interview, this file is the answer to "tell me about something
you built", and by the time you are writing a resume, it is the source
material.

Format:

```
## Week of YYYY-MM-DD
Shipped: what actually got pushed
Learned: one thing, specific
Stuck on: what is blocking, if anything
Next: the single most important thing for next week
```
